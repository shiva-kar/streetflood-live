# StreetFlood Live — production roadmap

Rule: everything must be free (GitHub Pages hosting, free Supabase, free OpenStreetMap / Open-Meteo services).

- [x] Worldwide place search + phone GPS
- [x] Live rainfall + 3-hour forecast (Open-Meteo)
- [x] Dynamic ~100 m street cells anywhere (no fixed Mumbai box)
- [x] Real help points / shelters from OpenStreetMap
- [x] Flood-aware routing (walking / driving) with real roads
- [x] New scoring engine (recency decay, confirmations, closures) + tests
- [x] Phone-first redesign: search bar, bottom panel, 5 tabs, 3-tap report
- [x] Emergency numbers by country + preparedness checklist
- [x] Community backend on free Supabase (schema, roles, rate limit, photos, live updates) + local fallback
- [x] Moderator tools (verify / dismiss, closures, alerts) for moderators
- [x] Daily keep-awake GitHub Action for the free database
- [ ] Connect the user's free Supabase project — waiting on user (keys)
- [ ] Hindi / Marathi translations
- [ ] Offline mode / install as app
